# Améliorations interface intégrées à la V2

- bandeau d'installation masqué automatiquement en mode PWA autonome ;
- suppression du grand bloc jaune permanent de la V1 ;
- sélecteur de jours compact avec défilement fluide et indicateur à droite ;
- sélection distincte des plages `07h-13h`, `13h-19h`, `19h-00h`, `00h-05h`, `05h-07h` ;
- bouton « Toute la plage » appliqué uniquement à la plage sélectionnée ;
- compteur de saisie et pourcentage de créneaux renseignés ;
- matrice Chef / Adjoint avec en-tête et première colonne figés ;
- affichage dynamique du potentiel opérationnel par heure ;
- feuille de garde filtrable par date et plage ;
- affichage des postes non pourvus « À compléter » ;
- conservation des couleurs véhicule du classeur ;
- droits Agent / Chef / Adjoint / Admin ;
- identification automatique par email en mode Microsoft 365 ;
- boutons Chef `Actualiser`, `Verrouiller`, `Publier` connectés au repository ;
- page Admin de diagnostic ;
- indicateur réseau et dernière synchronisation ;
- nouveau Service Worker et nouveau cache V2 ;
- données de démonstration alignées sur la composition opérationnelle cible récente.
