# Application Gardes — build test iPhone

Cette version est une PWA de démonstration prête à être hébergée en HTTPS.

## Test sur iPhone

1. Héberger le contenu du dossier sur une URL HTTPS.
2. Ouvrir cette URL dans Safari sur l'iPhone.
3. Toucher **Partager**.
4. Choisir **Sur l'écran d'accueil**.
5. L'icône `Gardes` apparaît sur l'iPhone et l'application s'ouvre en plein écran.

## Contenu testable

- sélection de l'agent ;
- saisie des disponibilités heure par heure ;
- bouton « Toute la plage » ;
- statuts Travail / Formation / École / GFF / GRR / Vacances / Maladie ;
- choix d'un remplaçant ;
- persistance locale des saisies ;
- vue feuille de garde ;
- vue Chef / Adjoint ;
- mode hors ligne après première ouverture.

## Important

Cette version utilise un stockage local pour le test. Elle n'est pas encore reliée à SharePoint / Power Automate.
Le raccordement au module VBA de synchronisation sera fait dans la version de production.
