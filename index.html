Guide

Comment utiliser l’application ?

1 · Identification de l’agent

En mode Microsoft 365, l’application recherche automatiquement l’adresse du compte connecté dans la liste Agents. L’agent ne voit alors que ses propres disponibilités.

2 · Saisir les disponibilités

Choisis le jour puis la plage horaire. Touche chaque heure ou utilise Toute la plage. Les statuts correspondent aux valeurs reconnues par le classeur Excel.

3 · Déclarer un remplaçant

Choisis Remplaçant, puis la personne concernée. La saisie est envoyée dans tblApp_Saisies du classeur Excel, puis le module VBA la reprend dans Demande dispo.

4 · Feuille de garde

La vue Garde lit les affectations publiées par le classeur. Les postes non pourvus restent visibles si l’option correspondante est activée.

5 · Chef de garde / Adjoint

La matrice conserve la première colonne et les heures pendant le défilement. Les actions Verrouiller, Publier et Actualiser écrivent directement dans les tables techniques du classeur Excel.

6 · Installer sur iPhone

Ouvre l’application dans Safari → Partager → Sur l’écran d’accueil. Le bandeau d’installation disparaît automatiquement lorsque l’application est déjà ouverte en mode autonome.

7 · Chaîne de synchronisation
  1. iPhone → tblApp_Saisies dans le fichier Excel.
  2. Excel Desktop détecte la nouvelle saisie.
  3. VBA → Demande dispo puis Remplir_Feuille_Gardes_En_W.
  4. Mois complet (Diffusion) → tblApp_Affectations.
  5. L’application relit directement le résultat via Microsoft Graph.
