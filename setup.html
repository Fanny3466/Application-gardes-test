APPLICATION GARDES · V2.3.2

Assistant de mise en production

Connexion Microsoft 365 → test du fichier Excel → génération de production-config.js.

1 · Application Microsoft Entra

Crée une inscription d’application de type Single-page application (SPA). N’ajoute jamais de client secret dans une application GitHub Pages.

URI de redirection à déclarer dans Entra : https://fanny3466.github.io/Application-gardes-test/ https://fanny3466.github.io/Application-gardes-test/setup.html

2 · Fichier Excel

Le fichier doit être dans SharePoint ou OneDrive Entreprise et contenir les tables créées par le module Excel Direct V1.2.

Lors du test, l’assistant associera le compte Microsoft connecté à ce code dans tblApp_Agents et lui attribuera le rôle ADMIN.

3 · Test réel

Authentification par redirection : cette version n’utilise plus de popup Microsoft. Elle évite ainsi les erreurs interaction_in_progress et block_nested_popups.

En attente.

4 · Configuration générée

Le lien de partage n’est pas conservé. Seuls les identifiants du fichier sont placés dans le fichier final.

Dernière étape : remplace à la racine de GitHub le fichier production-config.js par celui généré, puis attends le déploiement Pages.
