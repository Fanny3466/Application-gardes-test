# Tables Excel Direct

- `tblApp_Agents` : miroir de `Equipe de garde`
- `tblApp_Creneaux` : créneaux issus de `Demande dispo`
- `tblApp_Disponibilites` : miroir + zone d'écriture mobile
- `tblApp_Affectations` : export de `Mois complet (En W)` / `Mois complet (Diffusion)`
- `tblApp_Verrous` : verrouillage depuis l'application
- `tblApp_Publications` : demandes de publication
- `tblApp_Commandes` : commandes `RECALCULER`, `SYNCHRONISER`, `ACTUALISER_EXPORTS`, `PUBLIER_GARDE`
- `tblApp_Journal` : journal technique dans l'onglet existant `Journal application`
