# Remplacement rapide sur GitHub

## À remplacer au minimum

À la racine du dépôt `Application-gardes-test`, téléverser et remplacer :

- `index.html`
- `app.js`
- `repositories.js`
- `config.js`
- `sw.js`

Le plus sûr reste de téléverser **tout le contenu du ZIP V2.0.1** à la racine.

## Puis sur l'ordinateur

Ouvrir :

`https://fanny3466.github.io/Application-gardes-test/?v=201`

Le paramètre `?v=201` aide à éviter un cache de navigation ancien.

## Puis sur l'iPhone

1. Fermer l'ancienne app Gardes.
2. Ouvrir l'URL dans Safari avec `?v=201`.
3. Recharger la page.
4. Si l'ancienne V1/V2 reste en cache, supprimer l'icône de l'écran d'accueil puis la recréer depuis Safari.
